### ⚡ About Me

Saya **Ahmad Syarif Hidayatullah**, mahasiswa **Bisnis Digital di Universitas Negeri Makassar (UNM)** dan seorang **Full Stack Web Developer**.

Saya merancang dan membangun website, sistem *full-stack*, dashboard CMS, serta platform operasional yang menerjemahkan kebutuhan bisnis dan alur organisasi menjadi produk digital terukur yang siap digunakan. Pendekatan saya berfokus pada:
- **Konteks Masalah & Alur Pengguna:** Memetakan kebutuhan, struktur informasi, dan UX sebelum masuk ke implementasi kode.
- **Arsitektur Terukur & Bersih:** Membangun antarmuka responsif, integrasi RESTful API yang solid, serta basis data yang efisien dan mudah dirawat.
- **Ekosistem Modern:** Mengembangkan solusi menggunakan teknologi utama seperti **Next.js**, **Django**, dan **Laravel**.
